# Al Villaggio dei Bambini – Landing page

Sito statico (HTML + CSS + JS, nessuna dipendenza) della sala feste per bambini **Al Villaggio dei Bambini**, Via Mugnano-Giugliano 17.

## Pubblicazione con GitHub Pages
1. Settings → Pages
2. Source: *Deploy from a branch* → Branch `main`, cartella `/ (root)` → Save
3. Dopo 1–2 minuti il sito è online su `https://<utente>.github.io/<repo>/`

## Modifiche frequenti
- **Numero WhatsApp**: in `index.html` cerca `var WA = '393935309724'`
- **Foto**: cartella `img/` (stessi nomi file per sostituirle)
- **Dominio personalizzato**: Settings → Pages → Custom domain
